Privacy Policy

Last updated: October 31, 2026

This policy describes how MGSKJ_upload (the "app") handles data. The app is used only by its operator to manage the operator's own YouTube channel.

Google user data the app accesses

With the channel owner's permission (Google OAuth), the app uses these YouTube Data API scopes:

  • youtube.upload — upload the operator's videos and thumbnails.
  • youtube.readonly — read the channel's ID and title and its videos, to confirm the correct channel, avoid duplicate uploads and show scheduled videos.
  • youtube.force-ssl — at the operator's request, change the privacy status, publish time or details of the channel's own videos, or delete them.

How the data is used

The data is used only to perform the actions above, at the operator's request. It is not used for advertising, not sold and not shared with third parties. In this operation the app's optional AI title feature is turned off, so no video is sent to any AI service.

Storage

The OAuth refresh token, the app's client configuration, settings and upload history are stored only in the app's user data folder on the operator's own computer. Nothing is stored on this website or on any other server run by the operator. Google API requests are made through the operator's own browser profile (Multilogin) on that computer.

If the operator turns on the optional Telegram notification, upload results (video title and link) are sent to the operator's own Telegram chat.

Information from other people

The app does not collect personal information from viewers or any other person. The operator uses no analytics, advertising or tracking on this website. The hosting provider may set a short-lived security cookie to block automated abuse.

Revoking access and deletion

Access can be revoked at any time in your Google Account under Third-party connections. Revoking access stops the app from using the YouTube account. To have locally stored data deleted, contact the operator at the address below; the local token and history are deleted on request.

Limited Use

MGSKJ_upload's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
